# Реєстр автентичності картин

Цей проєкт містить дві сторінки:

- **index.html** — публічна сторінка перевірки (на неї веде QR-код на сертифікатах)
- **generator.html** — приватний генератор кодів (вводите секретний ключ + дані картини, отримуєте код)

## Як додати нову картину в реєстр

1. Відкрийте файл `index.html` на GitHub (натисніть на нього у списку файлів)
2. Натисніть на іконку олівця (✏️) у верхньому правому куті — це відкриє редактор
3. Знайдіть розділ, що починається з `const PAINTINGS = [`
4. Скопіюйте приклад запису і вставте свої дані, за зразком:

```js
{
  code: "ОК-2026-047-X9K2",
  title: "Осінній сад",
  note: "олія, полотно, 60×80 см",
  photo: "",
  addedAt: "2026-10-19"
},
```

5. Прокрутіть вниз, натисніть зелену кнопку **"Commit changes"**
6. Через 30–60 секунд зміни з'являться на сайті

## Фото картини

Найпростіший спосіб додати фото:
1. Завантажте фото картини на будь-який хостинг зображень (наприклад, imgur.com — безкоштовно, без реєстрації)
2. Скопіюйте пряме посилання на зображення (має закінчуватись на .jpg/.png)
3. Вставте це посилання в поле `photo: "..."` замість порожнього рядка
