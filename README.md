# Реєстр автентичності картин

Файли в цьому репозиторії:

- **index.html** — публічна сторінка перевірки коду (на неї веде QR на сертифікатах)
- **catalog.html** — галерея всіх картин із фото
- **generator.html** — приватний генератор кодів (не показуйте нікому)
- **paintings.csv** — ваша таблиця з картинами (єдине, що треба редагувати щодня)

## Як додати нову картину

1. Відкрийте файл `paintings.csv` у репозиторії
2. Натисніть на іконку олівця (editing pencil) у верхньому правому куті
3. У кінці файлу додайте новий рядок за зразком:

```
ОК-2026-002-F3K9,Весняний ліс,"акрил, полотно, 40×60 см",https://i.imgur.com/приклад.jpg,2026-10-20,Spring forest,"acrylic on canvas, 40×60 cm"
```

Поля через кому: `code,title,note,photo,addedAt,title_en,note_en`

`title_en` і `note_en` — англійська назва й опис (необов'язково). Якщо порожні, на англомовній версії покажеться українська.

- Якщо в описі (`note`) є кома — беріть усе поле в лапки `"..."`, як у прикладі з рядком "олія, полотно, 50×70 см"
- `photo` можна лишити порожнім — тоді просто не буде фото
- Дата (`addedAt`) у форматі РРРР-ММ-ДД

4. Натисніть зелену кнопку **"Commit changes"** внизу сторінки
5. Через 30–60 секунд новий запис з'явиться і в перевірці, і в каталозі

## Фото картини

1. Підготуйте фото: довга сторона ~1600 px, розмір до 500 КБ, назва латиницею без пробілів (наприклад, `OK-2026-001.jpg`).
2. У репозиторії відкрийте папку `photos` → Add file → Upload files → перетягніть фото → Commit changes.
3. У `paintings.csv`, у колонці `photo`, напишіть лише назву файлу: `OK-2026-001.jpg`.

Фото показується повністю, без обрізання, у рамі з паспарту; будь-які пропорції (вертикальні, горизонтальні, квадратні, панорами). По кліку відкривається на весь екран. Можна також вставити повне посилання `https://...` на фото з іншого місця.

## Шрифти й стиль

Колір і шрифти бренду задані в `brand.css`. Використані шрифти (обидва під ліцензією SIL OFL, комерційне використання дозволене):
- **Philosopher** — файли вже в папці `fonts/` разом з ліцензією
- **FoglihtenNo06** — покладіть файл `FoglihtenNo06.ttf` у папку `fonts/` (Add file → Upload files)

## Дизайн і мови

- Логотип — файл `logo.png` (щоб замінити, завантажте новий із такою самою назвою).
- Фон за замовчуванням темно-синій. Щоб зробити бордовим, у файлах `index.html`, `catalog.html`, `generator.html` змініть `<html lang="uk"` на `<html lang="uk" data-theme="burgundy"`.
- Мова UA/EN перемикається кнопками вгорі, вибір запам'ятовується в браузері.
